# 架构总览

这一阶段回答两件事：**这个内核整体长什么样**，
以及**代码能挂在哪几个口子上**。
第一篇画骨架：模块怎么分、进程有哪些、进程之间怎么说话、扩展点在哪；
第二篇往下拆一个具体机制，从入口一路读到每一行代码。

不展开单个机制的细节——锁、WAL、MVCC 的内部实现各归后面的阶段。
