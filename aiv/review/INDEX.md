## 怎么跑

```sh
cd aiv/pipeline
make review-text  EP=<EP>     # 文本层
make review-video EP=<EP>     # 成片层（需要 out/<EP>.mp4）
make review-frames EP=<EP>    # 抽帧 + 清单（帧不入库）
```
