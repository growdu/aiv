# review/scope/ —— 范围与分类判据

> **是什么**：什么内容**进这个仓库、归到哪个分类**的判据。决定一篇稿子的归属与
> 「该不该收」，与 [`../specs/`](../specs/) 的接口判据互补。

---

## 一、清单

按 `YYYY-MM-DD-scope-主题.md` 命名，例如 `2026-11-14-scope-classification.md`（范围分类）。

## 二、AI 如何使用本目录

- 新增一篇稿子、拿不准**归到哪个分类/该不该收**时，读这里的范围判据。
- 分类是**目录即接口**（见 [`../specs/2026-11-18-目录即接口与分类增设.md`](../specs/)）：
  一级目录 = 分类，二级目录 = 二级内容，一篇文档 = 一个目录。
- 范围是**判据文档**：判断「对不对」看这里 + [`../specs/`](../specs/)，不是靠感觉。
