## Global Constraints

这几条对每个 Task 都成立。**每条都照抄规格里的原话或仓库里的既有规矩，不许自行发挥。**

1. **存量不回炉。** `docs/` 现在是空的，这一轮**不写任何内容**——所有新用例一律在 `tmp_path` 里自己造语料。
   > 「一条用例如果依赖「仓库里曾经有过的内容」，它迟早会因为内容被清掉而变成假红。新的用例一律在自己造语料。」
2. **验收按模块拆开。** 每个模块一条命令，跑在自己的目录里（清单见 `acceptance/README.md`）。跨模块只验接口。
3. **模块之间不互相 import；上层要下层的东西只准通过文件要。** 契约层（`publish/publishkit/`）**不许** import 根 `tools/`（`publish/tests/test_episode.py` 守着这条）。共享规则 JSON 是**文件**，不是 import。
4. **路径常量只有一处：** `tools/paths.py`。契约层除外（它自己定）。
5. **URL 形状只有一处：** `rules/urls.json`。任何模块不许再写死 `"/docs/"`、`"/videos/"`。
6. **落地地址统一成 `/docs/<id>/`；** `/YYYY/MM/DD/<content_id>/` 不再产出。
7. **期身份四层**（`系列/合集/文档/档位`）；**成片分目录**；**outbox 扁平**。
8. **退出码语义**（五个 adapter 一致）：`0` 成功 / `1` 用法错 / `2` 缺前置条件 / `3` 做事失败。argparse 默认的「用法错退 2」要改成 1。
9. **框架源码里不许出现站名——全仓库。** 值全在使用者那一侧（`site.json` / `video/config.toml` / `capability.toml` / 环境变量）。
10. **提交粒度：** 一个 Task 一次提交（Task 内可多次）。提交信息用中文，**不加 `Co-Authored-By`**。
    **暂存区只放本 Task 的文件**：一条一条 `git add <具体文件>`，
    **不许 `git add -A`，也不许 `git add <目录>`**（裁决 R22）——
    这个仓库里有并行的 Claude 会话，整树/整目录扫会把别人的工作区状态卷进来。
    本 Task 新建的文件也**一条一条加进来**；提交前 `git status --short` 看一眼暂存区，
    本 Task 之外的东西一个都不许有。
11. **每次提交前跑一遍受影响模块的套件**（命令见各 Task），**红的必须归零**；跨模块的改动要跑全矩阵（`acceptance/README.md` §三）。
12. **文档跟着代码走：** 行为变了就改对应的 README / 规格，别留过时的说法。

### 三处「规格的字面写法 vs 本计划的落地」

规格 §七 定了方向，但有三处字面写法在实现时读不下去。**本计划按下面这三条落地，
做的时候照这三条走；评审时也照这三条看。**

1. **共享规则住在 `rules/`（仓库根的独立目录）。**
   规格 §七.1 说「落点：共享规则住在一个**入库的独立目录**里（不放 `content/units/` 旁边）」。
   本计划把它落成根目录的 `rules/urls.json`。
   —— **不是**根 `tools/`：那里放的是「站点要用的东西」，规则放进去站点就成了它的下游，
   依赖方向反了（§七.1 表格里否掉的 B 走法）。
   —— **不是** `content/units/` 旁边：那是 `.gitignore` 掉的构建产物，不是一份入库的真相。

2. **分类名 → 分类单元 id 的映射，由编译器写进内容单元；共享 JSON 放的是「地址形状」。**
   规格 §七.3 说了两件事：映射「由**编译器**算出来**写进内容单元**」，
   又说「映射放在那份 JSON 里」。**这两句不能同时照做**——
   一份入库的 JSON 装不下「随内容变」的映射（加了新分类就得改 JSON，而 JSON 是人手改的，
   编译器才是那个知道分类链的人）。
   本计划取：**编译器把映射写进内容单元的 `category_ids` 字段**（Task 5），
   **`rules/urls.json` 放的是「id → 地址」的形状**（`doc_prefix` / `category_suffix`），
   站点与 adapter 各自从它取形状、各自拿 id 去拼——**两边不各算一份形状**，
   规格 §七.3 的本意（一份真相）达到了。

3. **署名（author）从内容单元来，不从 `site.json` 来。**
   规格 §三 的清单写「`platforms/wechat/brand.py` 默认署名 → 站点身份（`site.json` 的 author）」，
   但 `site.json` **今天没有 author 字段**，而且让 adapter 去读站点的配置是**跨模块依赖**。
   本计划取：**作者写在母稿的 front matter 里** → 编译器透传进内容单元 → adapter 读内容单元的
   `author` 字段；编译器不再替使用者补默认值（Task 12）。
   —— 母稿要写作者就写 `author:`。**署名不是框架决定的，是内容决定的。**

## Review Focus

规格说了「要怎样」但没说「这些输入怎么办」的五件事——每一条都写成了**拥有它的那个 Task 里的测试**。做的时候别跳过。

1. **一条 `description` 超过 80 个字。** 编译器今天用 `yaml.safe_dump` 折行，契约层的解析器只读第一行 → 描述被截断成半句（`publishkit.contract.parse_front_matter` 只取首个物理行）。→ Task 2 的 `test_a_long_description_survives_the_round_trip`。
2. **分类链有两级同名。** 分类名 → 分类内容单元 id 的映射是**平行列表**（`categories` 与 `category_ids` 同序）；名字重复或顺序变了，映射就错位 → 拼出别的分类的地址。→ Task 5 的 `test_the_two_category_lists_stay_aligned`。
3. **没有配 `SITE_URL`。** 公众号的「阅读原文」与头条的「完整版见 …」不能变成半截话（`完整版见 ` 后面空着），也不能默默指向 `https://growdu.cn`。→ Task 12 的 `test_no_site_url_means_no_half_a_sentence`。
4. **一期视频的成片挪到了嵌套目录。** `preflight` / `review` 找不到成片时要报「成片不在本机」，而不是别的错（现在 `pyv/cli.py` 与 `pyv/review.py` 各算一遍路径，改一处漏一处就找不到成片）。→ Task 8 的 `test_the_cut_path_is_nested_under_the_episode`（成片路径收进 `episodes.cut_path`，一处算两处用）。
5. **守卫扫源码时，测试文件与 markdown 里的实例名不该让它变红。** 站名出现在测试夹具、README、规格里都是正常的；守卫只扫**框架源码**（代码文件，排除 `tests/`、`out/`、`outbox/`、`dist/`、`node_modules/`、`.md`）。→ Task 15 的 `test_the_guard_ignores_tests_and_documents`。

  ```python
  """共享 URL 规则的守卫：**形状只有一份**。"""
  import json, re, subprocess
  from pathlib import Path

  REPO_ROOT = Path(__file__).resolve().parents[4]
  RULES = REPO_ROOT / "rules" / "urls.json"

  def test_the_rules_file_is_tracked_by_git():
      out = subprocess.run(["git", "ls-files", "--error-unmatch", "rules/urls.json"],
                           cwd=REPO_ROOT, capture_output=True, text=True)
      assert out.returncode == 0, "rules/urls.json 必须入库——它是一份真相，不是构建产物"

  def test_the_rules_file_carries_every_key_the_readers_need():
      data = json.loads(RULES.read_text(encoding="utf-8"))
      for key in ("doc_prefix", "video_prefix", "video_id_prefix", "category_suffix"):
          assert data[key], f"规则里少了 {key}"

  def test_the_site_source_does_not_hardcode_the_doc_prefix():
      """站点不许自己写死 '/docs/'——它得从规则里取。"""
      offenders = []
      for path in sorted((REPO_ROOT / "platforms/blog/site/src").rglob("*")):
          if path.suffix not in {".astro", ".ts", ".mjs", ".css"}:
              continue
          if "content" in path.relative_to(REPO_ROOT / "platforms/blog/site/src").parts:
              continue
          text = path.read_text(encoding="utf-8", errors="ignore")
          if re.search(r"""['"`]/docs/""", text):
              offenders.append(str(path.relative_to(REPO_ROOT)))
      assert not offenders, f"这些地方写死了 '/docs/'：{offenders}"

  def test_the_python_url_producers_do_not_hardcode_the_doc_prefix():
      offenders = []
      for rel in ("publish/publishkit/urls.py", "tools/url_rules.py",
                  "platforms/blog/cli.py", "platforms/blog/site/tools/build-activity.py"):
          text = (REPO_ROOT / rel).read_text(encoding="utf-8")
          if re.search(r"""['"]/docs/""", text):
              offenders.append(rel)
      assert not offenders, f"这些地方写死了 '/docs/'：{offenders}"
  ```

  新建 `tests/test_instance_identity.py`：

  ```python
  """**全仓库**的身份守卫：框架源码里不许出现站名。

  规矩的适用范围 2026-11-19 由 owner 定成「全仓库」——
  以前只有站点一个模块守着（site/tests/test_site_config.py），
  别的模块没人管，于是实例身份还留在源码里。

  **扫描范围**：框架源码（代码文件），**不含**测试夹具、markdown 文档、
  构建产物、配置缝本身——站名出现在那些地方是正常的。
  """
  import subprocess
  from pathlib import Path

  REPO_ROOT = Path(__file__).resolve().parents[1]

  #: 扫哪些后缀（代码）。
  CODE_SUFFIXES = {".py", ".ts", ".tsx", ".mjs", ".js", ".astro", ".css", ".sh"}

  #: 扫哪些目录（相对仓库根）。
  SCAN_DIRS = ("tools", "publish", "platforms", "video/pipeline/pyv",
               "video/brand/scripts", "browser/browser")

  #: 这些目录不扫：测试、构建产物、内容副本。
  SKIP_PARTS = {"tests", "test", "out", "outbox", "dist", "node_modules",
                 "__pycache__", "docs", "content"}

  def _instance_tokens() -> list[str]:
      """从各个缝里读出「这个实例叫什么」。"""
      tokens = set()
      site = REPO_ROOT / "platforms" / "blog" / "site" / "data" / "site.json"
      if site.is_file():
          import json
          name = json.loads(site.read_text(encoding="utf-8")).get("name")
          if name:
              tokens.add(name)
      brand = REPO_ROOT / "video" / "config.toml"
      if brand.is_file():
          import tomllib
          data = tomllib.loads(brand.read_text(encoding="utf-8"))
          for key in ("name", "token", "site"):
              value = (data.get("brand") or {}).get(key)
              if value:
                  tokens.add(value)
          slug = (data.get("character") or {}).get("slug")
          if slug:
              tokens.add(slug)
      return sorted(t.lower() for t in tokens if len(t) >= 3)

  def _framework_sources():
      for rel in SCAN_DIRS:
          root = REPO_ROOT / rel
          if not root.is_dir():
              continue
          for path in sorted(root.rglob("*")):
              if not path.is_file() or path.suffix not in CODE_SUFFIXES:
                  continue
              parts = set(path.relative_to(REPO_ROOT).parts)
              if parts & SKIP_PARTS:
                  continue
              yield path

  def test_the_guard_finds_the_instance_name_somewhere():
      """守卫本身要能抓到东西——不然它只是一段没人跑过的代码。"""
      assert _instance_tokens(), "从缝里读不出实例名，守卫无从谈起"

  def test_no_framework_source_mentions_the_instance():
      tokens = _instance_tokens()
      offenders = []
      for path in _framework_sources():
          text = path.read_text(encoding="utf-8", errors="ignore").lower()
          for token in tokens:
              if token in text:
                  offenders.append(f"{path.relative_to(REPO_ROOT)}（{token}）")
                  break
      assert not offenders, (
          "框架源码里出现了实例身份——它只该待在缝里：\n"
          + "\n".join(offenders)
      )

  def test_the_guard_ignores_tests_and_documents():
      """测试夹具与 markdown 里的站名是正常的——守卫不许把它们算成违规。"""
      for path in _framework_sources():
          assert "tests" not in path.parts
          assert path.suffix != ".md"
  ```
