# review/plans/ —— 审校层实施计划（过程文档）

> **是什么**：审校层与内容结构调整的**实施计划**（怎么拆任务、怎么验收）。
> 是过程文档——判据在 [`../specs/`](../specs/)，计划落地后权威真相回到规格里。

---

## 一、清单

按 `YYYY-MM-DD-主题.md` 命名的实施计划，例如：
- `2026-11-18-层间接口与内容坐标系实施.md`
- `2026-11-19-接口欠账实施.md`
- `2026-11-20-站点换hexo实施.md`

每条对应一次结构/接口/流水线的大改，记录任务拆解与验收口径。

## 二、AI 如何使用本目录

- 想理解「某次结构大改当初怎么拆的」→ 读对应计划。
- **计划不是判据**：判断「现在对不对」看 [`../specs/`](../specs/)，不是看计划。
- 与 [`../../publish/plans/`](../../publish/plans/) 分工：这里管审校/内容/结构，那里管发布/视频发布。
