# 信息架构

一个站有两百篇文章的时候，「分类」就不再是导航了，它只是一个检索框。

读者从搜索引擎落在一篇文章上，看完想接着读什么——
站点如果不给答案，他就走了。这一系列讲的是：
**怎么给一个内容堆得越来越大的个人站设计一条能读下去的路。**
