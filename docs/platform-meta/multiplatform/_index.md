# 多平台分发

同一个内容单元，发到公众号、头条号、抖音、视频号、B 站，
每个平台的形态、限额、自动化程度都不一样。

这一系列要讲的是：怎么把这些差异**从代码里抽出来变成数据**，
怎么保证「重复跑一遍不会发两遍」，以及为什么这套系统的自动化
**故意停在半路**。

## 本系列文章

本系列尚未成稿。第一篇会讲平台能力模型：
为什么「一个平台一份声明文件」能顶掉五套 if-else，以及
「加平台 = 加一份声明，不改代码」到底意味着什么。

那份声明现在住在 `platforms/<plat>/capability.toml`——
目录名就是平台 id，也是 Python 包名；平台自己的发布快照住在
同目录下的 `outbox/`。
