# PostgreSQL

这一条线照着 PostgreSQL 19 的源码走。阶段划分与学习流里登记的
`postgresql` 赛道一一对应，每个阶段一个目录：

| 阶段 | 主题 | 状态 |
| --- | --- | --- |
| L1 | 架构总览 | [架构总览](./getting-started/_index.md) |
| L2 | 存储引擎：页、文件与内存 | 未开目录 |
| L3 | 索引与查询执行 | 未开目录 |
| L4 | 事务、MVCC 与并发 | 未开目录 |
| L5 | WAL、checkpoint 与恢复 | 未开目录 |
| L6 | 复制与高可用 | 未开目录 |
| L7 | 逻辑复制与流式 | 未开目录 |
| L8 | 扩展、性能与生态 | 未开目录 |

「未开目录」的意思是那一层还没有稿子，目录也就没建——
**目录只在有内容可放的时候才开**。等 L2 的稿子写完，这一行会变成一个链接。

L1 里的这一篇把后面几层的骨架先摊了一遍：
模块怎么分、进程有哪些、进程之间怎么说话、扩展点在哪——
**只到「结构与坐标」这一层，细节仍归各自的阶段**。

版本基准：PostgreSQL 19（源码树 `REL_19_STABLE`）。
每篇文章的结论都给源码入口，或者给能直接跑的命令。
