# 内置字体子集里，**GB 2312-80 之外、但要能画出来的字**。
#
# **为什么要有这个文件**：子集的**底子**是 GB 2312-80 全集（汉字区
# 6763 字 + 符号区）——那是标准，母稿的常用字全在里面。
#
# 但标准盖不住全部：生僻人名（䶮 龘）、方言词、emoji 之类，
# 母稿里真的会出现。**这些字不能画成豆腐块**——豆腐块没人看得出来，
# 而画面照样生成、时长照样对，没有任何报错。
#
# **所以**：字不在标准里、又**字库里有**的时候，把它加到这个文件里，
# 然后重跑 `scripts/build_font_subset.py`。子集就会盖住它。
#
# **一个字库根本没有的字，加进来也没用**：脚本会当场报错说
# 「上游字体里没有这些字形」。例如 `⌊` `⌋`（U+230A/230B）——
# Noto Sans CJK **没有**这两个字形（实测：源字体 cmap 里查不到），
# 换任何子集都画不出来。母稿真用到它们时，只能改写法或者换字库。
#
# **为什么是文件而不是写死在脚本里**：这是**数据**，不是逻辑。
# 内容不入库，但「哪些字要能画出来」是**产物的事实**——它跟着
# 母稿走，跟着入库的子集走。
#
# **一个字符一行**；空行与 `#` 开头的行是注释。
#
# **别把常用字加进来**：常用字在 GB 2312-80 里，加进来是白加
# （子集不变）。这里只放标准盖不住、而字库有的。
#
# 现在是空的——当前入库的母稿没有需要额外补的字。
