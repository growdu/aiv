## 二、AI 如何使用本目录

- 想理解「某块发布功能当初打算怎么做」→ 读对应计划，再对照 [`../spec/`](../spec/) 看落地成什么样。
- **计划不是判据**：判断「现在对不对」看 `../spec/` 与 [`../tests/`](../tests/)，不是看计划。
- 新计划按 `NN-主题.md` 编号，与 `../spec/` 的编号序列**分开**（一个管规格、一个管过程）。
- **计划四（`12-…`）已落地**：母稿汉字画得出来（盖不住的字当场报错）、代码块用真等宽、
  通用渲染器有逐像素基准、画面人眼过了一遍。计划二（`10-…`）的「遗留」四条
  已改写成指向它——**看计划二的遗留前，先看计划四**。
