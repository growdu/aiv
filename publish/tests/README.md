# publish/tests/ —— 契约层验收套件

> **这是什么**：发布契约层的测试。它验证契约层**自己的实现**正确，
> 以及**层间缝**没破（不 import 平台层、退出码取值一致、期号口径一致等）。

---

## 一、怎么跑

```bash
cd .. && python3 -m pytest tests/ -q     # 在 publish/ 目录里跑
```

## 二、AI 如何使用本目录

- **改 `../publishkit/` 后先跑这一套**——它是发布契约层的红线。
- 关注**缝**的测试：层间零 import、退出码取值、期号/视频坐标口径（与 `video/pipeline/pyv/episodes.py` 对齐）。
- 跨模块只验**接口**，不验平台实现——平台 adapter 的验收在它们各自目录里跑。
